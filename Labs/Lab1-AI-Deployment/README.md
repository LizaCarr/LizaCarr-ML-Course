# AI Model Deployment with TensorFlow Lite

## Overview
This lab focused on understanding how machine learning models are prepared and deployed on edge devices. The goal was to explore the full lifecycle of an AI model, from training to deployment.

## What I Did
- Set up a Python development environment
- Installed TensorFlow and TensorFlow Lite
- Designed a simple neural network using the MNIST dataset
- Normalized and preprocessed data
- Trained the model using TensorFlow
- Converted the model to TensorFlow Lite format
- Simulated deployment using the TensorFlow Lite Interpreter

## What I Learned
I learned that building a model is only part of the process. Deployment requires optimization so the model can run efficiently on devices with limited resources such as memory and power.

## Challenges
- Understanding model conversion to TensorFlow Lite
- Learning how the interpreter loads and runs models
- Following the correct sequence for deployment steps

## Outcome
I successfully simulated deploying a machine learning model and gained a better understanding of how AI systems operate in real-world edge environments.
