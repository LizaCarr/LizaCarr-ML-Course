# Data Visualization with Python

## Overview
This lab focused on visualizing real-time sensor data using Python. The goal was to understand how data can be monitored through graphical representation.

## What I Did
- Created a Python script to simulate temperature and humidity data
- Used Matplotlib to create a real-time graph
- Displayed data changing over time
- Managed timestamps and multiple data values

## What I Learned
I learned how to create dynamic visualizations and how important visualization is in monitoring IoT systems.

## Challenges
- Formatting time labels correctly
- Updating graphs in real time
- Managing multiple data streams

## Outcome
I created a working real-time graph that shows temperature and humidity data, demonstrating how systems can be monitored visually.
