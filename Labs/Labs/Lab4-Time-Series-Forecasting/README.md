# Time Series Forecasting with Nixtla TimeGPT

## Overview
This lab focused on predicting future temperature values using time series forecasting techniques.

## What I Did
- Loaded and cleaned a dataset
- Converted datetime values and structured time-series data
- Applied MinMax scaling
- Used TimeGPT for forecasting
- Performed feature engineering (hour, lag, month)
- Evaluated performance using MAE and RMSE

## What I Learned
I learned how forecasting models work and how feature engineering improves accuracy. I also learned that adding more data does not always improve results.

## Challenges
- Debugging dataset formatting issues
- Handling time frequency errors
- Understanding evaluation metrics

## Outcome
I built a forecasting model that predicts temperature trends and evaluated different modeling approaches.
