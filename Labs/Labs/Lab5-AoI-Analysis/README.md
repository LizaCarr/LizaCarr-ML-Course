# IIoT Network Analysis: Age of Information

## Overview
This lab focused on analyzing Age of Information (AoI) and how data freshness affects system performance in IIoT environments.

## What I Did
- Loaded and explored a dataset
- Created visualizations (scatter plots, box plots, heatmaps)
- Analyzed relationships between variables
- Built a Random Forest model
- Evaluated performance using MSE and R²

## What I Learned
I learned how data freshness impacts decision-making and how machine learning can be used to analyze system performance.

## Challenges

- Understanding model evaluation metrics
- Visualizing complex datasets

## Outcome
I successfully analyzed AoI and built a predictive model, gaining insight into real-world IIoT systems.
