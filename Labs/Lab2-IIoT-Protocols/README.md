# IIoT Protocol Simulation and Data Visualization

## Overview
This lab focused on simulating an Industrial Internet of Things (IIoT) environment using three communication protocols: MQTT, CoAP, and OPC UA.

## What I Did
- Set up a Python environment
- Created scripts to simulate sensor data
- Configured an MQTT broker (Mosquitto)
- Sent temperature and humidity data in real time
- Visualized the data using Python and Matplotlib

## What I Learned
I learned how different IIoT protocols work. MQTT uses a publish-subscribe model, CoAP uses request-response, and OPC UA provides structured industrial communication.

## Challenges
- Setting up the MQTT broker correctly
- Running multiple scripts simultaneously
- Debugging communication errors

## Outcome
I successfully simulated real-time sensor communication and visualized the data, demonstrating how IIoT systems operate.
